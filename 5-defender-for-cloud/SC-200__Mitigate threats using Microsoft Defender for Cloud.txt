In Microsoft Defender for Cloud, an organization requires agentless vulnerability scanning, agentless malware scanning, and machine secrets scanning across virtual machines. Which plan must be enabled?	Defender for Servers Plan 2. (Plan 1 provides basic Defender for Endpoint integration and vulnerability management; Plan 2 adds agentless scans, network threat detection, and DNS protection).	DefenderCloud::Servers
An organization onboards non-Azure servers to Defender for Cloud using Defender for Endpoint Direct Onboarding instead of Azure Arc. What key capability is lost?	Centralized Azure management capabilities, including Azure Policy enforcement, extensions deployment, and guest configuration controls.	DefenderCloud::Onboarding
How does Defender for Cloud integrate entire AWS accounts or GCP projects into its security posture management versus managing individual non-Azure VMs?	Native Cloud Connectors integrate full AWS/GCP environment hierarchies, while Azure Arc-enabled servers onboard and manage individual virtual machines as Azure resources.	DefenderCloud::Multicloud
Which Defender for Cloud feature reduces management port exposure (e.g., RDP 3389, SSH 22) by dynamically opening inbound firewall rules only upon approved request?	Just-in-Time (JIT) VM Access. (Configures Network Security Group rules to block ports by default and open them temporarily for specific IP addresses).	DefenderCloud::WorkloadProtection
An administrator needs to prevent unauthorized binaries from running on Windows servers by automatically analyzing machine execution history and creating executable allowlists. What feature should be used?	Adaptive Application Controls.	DefenderCloud::WorkloadProtection
Which component handles File Integrity Monitoring (FIM) in Defender for Cloud for tracking critical OS file, registry, and application changes on Windows servers without the legacy Log Analytics agent?	The Microsoft Defender for Endpoint extension.	DefenderCloud::WorkloadProtection
How does Defender for Storage detect malware uploaded to blob storage containers without opening, inspecting, or downloading the actual stored files?	By evaluating storage activity telemetry and file hashes against Microsoft Threat Intelligence reputation data.	DefenderCloud::Storage
What component must be deployed to Azure Kubernetes Service (AKS) clusters so that Defender for Cloud can enforce Kubernetes security policies and block non-compliant pod deployments?	Azure Policy for Kubernetes.	DefenderCloud::Containers
Does Defender for Azure Cosmos DB or Defender for SQL inspect stored database content to detect SQL injection or data exfiltration?	No. Threat detection analyzes database service telemetry and management/data-plane operations, not stored database content.	DefenderCloud::Databases
An analyst receives a high-severity Defender for Resource Manager alert indicating unusual administrative subscription activity. Which Azure log source should be investigated?	The Azure Activity Log.	DefenderCloud::Investigation
A lab subnet frequently triggers benign network alerts in Defender for Cloud. How can an administrator automatically dismiss these alerts in the future with minimal effort?	Create a Defender for Cloud Suppression Rule. (Sentinel Automation Rules cannot close Defender for Cloud alerts directly).	DefenderCloud::Alerts
What is the primary operational difference in Defender for Cloud between a Suppression Rule and a Workflow Automation?	Suppression Rules automatically dismiss non-actionable alerts without triggering responses; Workflow Automation uses Azure Logic Apps to run automated remediation workflows when alerts or recommendations occur.	DefenderCloud::Automation
How does Defender for Cloud measure an organization's compliance against industry benchmarks like PCI-DSS, NIST, or CIS?	By grouping underlying Azure Policy definitions into Azure Policy initiative definitions and evaluating resource compliance on the Regulatory Compliance dashboard.	DefenderCloud::Posture
Following the retirement of standalone Defender for DNS, how is DNS threat detection provided for Azure virtual machines in Defender for Cloud?	DNS threat protection is included natively within Defender for Servers Plan 2.	DefenderCloud::Servers
Which log collection component replaced the legacy Log Analytics agent (MMA) in Defender for Cloud for deploying security agent configurations via Data Collection Rules (DCR)?	The Azure Monitor Agent (AMA).	DefenderCloud::Architecture
What mechanism in Defender for Cloud aggregates multiple distinct security alerts affecting related cloud resources into a single structured incident?	Cloud Smart Alert Correlation.	DefenderCloud::Investigation
In Defender for Cloud architecture, what is the core operational distinction between Cloud Security Posture Management (CSPM) and Cloud Workload Protection (CWP)?	CSPM assesses resource configurations and enforces security recommendations (Secure Score); CWP provides active runtime threat detection and alert generation across workloads.	DefenderCloud::Architecture
Why must on-premises or multi-cloud virtual machines be onboarded as Azure Arc-enabled servers to receive full Defender for Cloud posture management?	Azure Arc projects non-Azure machines into Azure Resource Manager, enabling Azure Policy evaluation, extension auto-provisioning, and unified inventory tracking.	DefenderCloud::Onboarding
During an incident investigation in Defender for Cloud, an analyst wants detailed context on the specific threat actor group, campaign tactics, and IoCs behind an alert. Where in the alert details can they find this?	In the integrated Threat Intelligence Report (Activity Group, Campaign, or Threat Summary Report).	DefenderCloud::Investigation
Why does remediating recommendations inside high-weight Security Controls improve a tenant's overall Secure Score faster than remediating individual isolated recommendations?	Secure Score is calculated by Security Control categories; max points for a control are awarded only when ALL resources within that control become fully compliant.	DefenderCloud::Posture
