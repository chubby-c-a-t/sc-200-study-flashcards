What is a large language model (LLM)?	A type of AI model designed to generate human-like text.	
What is the purpose of tokenization in generative AI?	To break down text into smaller units.	
What are embeddings in the context of generative AI?	Vector-based representations of tokens that capture their semantic meaning.	
What does an attention layer do in a transformer model?	Examines the relationships between each token and the tokens around it.	
What is the purpose of a system prompt?	To provide context and instructions to the AI model.	
What is an agent in the context of AI?	An AI system that can perform tasks on behalf of a user.	
What is the unit of measure for the computing power used to provision and run Microsoft Security Copilot?	Security Compute Units (SCUs).	
What are the four key elements of an effective prompt in Microsoft Security Copilot?	Goal, Context, Expectations, and Source.

What is a Security Copilot &quot;Workspace&quot;?	A separate, dedicated work environment within a tenant assigned its own SCU capacity, permissions, and plugin settings.
