In a Microsoft 365 E5 tenant, an analyst needs to review Data Loss Prevention (DLP) alerts triggered across SharePoint Online sites. Which two portals provide full access to view these DLP alerts?	The Microsoft Purview portal and the Microsoft Defender portal	DLP::Purview
During a DLP alert investigation in Microsoft Purview, an analyst needs to inspect the actual sensitive content inside a flagged document. Which tool should they use?	Content Explorer. (Use Activity Explorer to track historical user actions and data movements over time).	DLP::Purview
An organization needs to be notified if an employee downloads a large volume of documents from SharePoint Online during the month prior to their account deletion. Which Purview capability should be used?	"An Insider Risk Management policy based on the ""Data theft by departing users"" template."	
An analyst triages an Insider Risk Management alert and confirms suspicious exfiltration activity. What administrative action should they take next to manage the formal investigation?	Create an Insider Risk case. (Cases can later be resolved as Benign or Confirmed Policy Violation).	InsiderRisk::Purview
When running Advanced Hunting queries in Microsoft Defender XDR to correlate insider risk signals with endpoint telemetry, which two Purview tables store data security behaviors and events?	DataSecurityBehaviors and DataSecurityEvents (joined with AlertInfo and AlertEvidence).	InsiderRisk::Purview
An investigation requires analyzing detailed workload actions performed within Microsoft 365 by an application registered in Microsoft Entra. Why are Entra sign-in logs insufficient, and what log source must be used?	Entra sign-in logs only record authentication events; detailed workload activity must be audited using the Microsoft Purview Audit log.	Audit::Purview
An analyst needs to verify whether a specific user signed in to Microsoft 365 and shared a document stored in OneDrive for Business during the last 30 days. Which portal provides the authoritative audit log source for this activity?	The Microsoft Purview portal (Unified Audit Log).	Audit::Purview
An audit search in Microsoft Purview Audit (Standard) returns 80,000 matching records. The security team requires a full CSV export without missing data, but the tenant cannot be upgraded to Audit (Premium). What should they do?	Refine the audit search into multiple smaller time ranges to ensure each export remains under the 50,000-record Audit (Standard) limit.	Audit::Purview
An investigation requests Exchange Online and Microsoft Entra ID audit events from 9 months ago, but no results are returned. What auditing solution must be enabled to ensure logs remain searchable for at least 1 year going forward?	Microsoft Purview Audit (Premium). Audit (Standard) retains logs for up to 180 days.	Audit::Purview
Which Microsoft Purview Audit (Premium) event records explicit message-level access, allowing investigators to prove whether an attacker actually read specific emails during a mailbox compromise?	MailItemsAccessed.	Audit::Purview
An eDiscovery search targeting multiple custodians and SharePoint locations with wildcard keywords fails and returns error code CS007. What should the analyst do to resolve the failure?	Split the search into smaller searches by limiting custodians, locations, or date ranges to reduce query complexity.	eDiscovery::Purview
A Global Administrator attempts to access an active eDiscovery case in the Microsoft Purview portal but is denied. Why does this occur and how is it resolved?	Global Administrators do NOT receive automatic eDiscovery access; they must explicitly be assigned the eDiscovery Manager or Administrator role AND added as a case member.	eDiscovery::Purview
What key operational advantage does an eDiscovery Administrator have over an eDiscovery Manager in Microsoft Purview?	eDiscovery Administrators can view and manage all eDiscovery cases across the entire organization, whereas eDiscovery Managers can only access cases where they are explicitly added as members.	eDiscovery::Purview
During an eDiscovery investigation, what Purview feature allows legal analysts to freeze search results, perform deep indexing, analyze context, and redact sensitive documents prior to export?	A Review Set.	eDiscovery::Purview
A DLP alert is generated when sensitive data is uploaded to a personal cloud service. When should the investigation be transitioned from Microsoft Purview to Microsoft Defender XDR?	When broader cross-domain correlation is required across endpoint alerts, identity risks, and network telemetry to investigate a multi-stage attack.	DLP::Purview
Which Exchange Online PowerShell cmdlet is used by security administrators to programmatically query the central Microsoft Purview Unified Audit Log?	Search-UnifiedAuditLog.	Audit::Purview
