In Microsoft Sentinel, what distinguishes proactive threat hunting from alert triage or incident response?	Threat hunting starts before a detection has confirmed the threat and searches existing data for previously undetected malicious behaviour.	Sentinel::Hunting
In Microsoft Sentinel, what should drive a proactive hunt when there is no known indicator to search for?	A testable hypothesis based on threat intelligence, attacker tactics and techniques, environmental knowledge, or observed anomalies.	Sentinel::Hunting
What makes a Microsoft Sentinel threat-hunting hypothesis useful?	It is specific, testable, time-bound and scoped narrowly enough to validate with available data.	Sentinel::Hunting
Why is searching Microsoft Sentinel for a newly supplied malicious IP not, by itself, a complete proactive hunt?	It is an indicator search for a known observable. A proactive hunt tests a broader hypothesis for behaviour that existing detections might have missed.	Sentinel::Hunting
In Microsoft Sentinel, which feature organises queries, bookmarks, entities, comments and actions around one investigation hypothesis?	A hunt.	Sentinel::Hunts
In Microsoft Sentinel, what is the value of using a hunt rather than running unrelated hunting queries?	A hunt preserves the hypothesis, selected queries, evidence, entities, collaboration and resulting actions as one tracked investigation.	Sentinel::Hunts
In Microsoft Sentinel, what should analysts do when a hunt validates malicious activity?	Act on the findings by creating or updating an incident, creating a detection, adding threat intelligence, or running an appropriate response workflow.	Sentinel::Hunts
In Microsoft Sentinel, what should a completed hunt document?	The hypothesis, scope, data and queries used, evidence found, conclusion, reproducibility and recommended detection or response improvements.	Sentinel::Hunts
In Microsoft Sentinel, what does a hunting bookmark preserve?	A relevant query result together with the query and analyst context such as notes and tags.	Sentinel::Bookmarks
In Microsoft Sentinel, when should a hunting bookmark be promoted to an incident?	When the bookmarked evidence represents activity requiring formal investigation, ownership, tracking or response.	Sentinel::Bookmarks
In Microsoft Sentinel, which table stores hunting bookmark records?	<code>HuntingBookmark</code>.	Sentinel::Tables
In Microsoft Sentinel, when should a search job be used?	When investigating specific events across very large datasets or long-term retention and an ordinary interactive query is unsuitable or times out.	Sentinel::SearchJobs
In Microsoft Sentinel, what does a search job do with matching records?	It runs asynchronously and writes matching records to a new analytics table whose name ends in <code>_SRCH</code>.	Sentinel::SearchJobs
In Microsoft Sentinel, when should archived data be restored instead of only searched with a search job?	Restore it when a full investigation requires high-performance interactive queries and broader KQL analysis over the historical table and time range.	Sentinel::Restore
In Microsoft Sentinel, how can you recognise a table created by restoring archived logs?	Its name ends in <code>_RST</code>.	Sentinel::Restore
In Microsoft Sentinel, what is the difference between a search job and restoring archived data?	A search job retrieves matching records into a search-results table; restore makes the selected historical table and time range available for high-performance investigation.	Sentinel::Compare
In Microsoft Sentinel, why are Jupyter notebooks useful for threat hunting?	They support repeatable programmatic analysis, enrichment, visualisation and multi-step investigations that go beyond a single KQL query.	Sentinel::Notebooks
Which Python package provides Microsoft-focused security investigation, enrichment and visualisation capabilities in Sentinel notebooks?	<code>msticpy</code>.	Sentinel::Notebooks
Which notebook extension allows KQL queries to be run from Jupyter with notebook magic syntax?	<code>Kqlmagic</code>.	Sentinel::Notebooks
In the Microsoft Sentinel data lake, when is a KQL job more appropriate than a traditional search job?	Use a KQL job for one-time or scheduled data-lake analysis, joins, unions, aggregation or promotion of selected results to the analytics tier; use a search job to retrieve specific events from large or long-retention Log Analytics datasets.	Sentinel::DataLake
In Microsoft Sentinel, which feature should run a scheduled aggregation and store a smaller analytics-tier dataset that analysts repeatedly query?	A summary rule.	Sentinel::SummaryRules
In Microsoft Sentinel, what is the difference between a summary rule and a KQL job?	A summary rule maintains scheduled aggregated results for repeated analytics-tier querying; a KQL job performs one-time or scheduled data-lake processing and can promote selected results to another tier.	Sentinel::Compare
When using the Microsoft Sentinel MCP server with access to multiple data-lake workspaces, how do you ensure tools query the intended workspace?	Use <code>list_sentinel_workspaces</code> to identify the workspace, then specify that workspace ID in the prompt.	Sentinel::MCP
For most Microsoft Sentinel MCP tools, what platform prerequisite is required?	Onboarding to the Microsoft Sentinel data lake.	Sentinel::MCP
What role is required to list and invoke the Microsoft Sentinel MCP tool collection?	Security Reader, with individual tools still limited by the caller's existing permissions.	Sentinel::MCP
