In Microsoft Sentinel, what is the difference between entity mapping and custom details in an analytics rule?	Entity mapping creates recognised investigation entities; custom details add selected query-result values to the alert without turning them into entities.	Sentinel::Analytics
In Microsoft Sentinel, what is the purpose of Fusion?	To correlate related low-fidelity signals and alerts across products into higher-confidence incidents using Microsoft-managed logic.	Sentinel::Analytics
Can the internal correlation logic of a Microsoft Sentinel Fusion rule be edited?	No. Fusion uses Microsoft-managed correlation logic.	Sentinel::Analytics
In Microsoft Sentinel, what is an anomaly analytics rule designed to identify?	Activity that deviates from learned behavioural baselines rather than matching a fixed signature or threshold alone.	Sentinel::Analytics
In Microsoft Sentinel, which table stores results generated by active anomaly rules?	<code>Anomalies</code>.	Sentinel::Tables
In Microsoft Sentinel, an incident-triggered playbook must run automatically when an NRT rule creates an incident. What should you configure?	An automation rule with a Run playbook action.	Sentinel::Automation
In Microsoft Sentinel, why is configuring the NRT rule's incident settings not enough to run an incident-triggered playbook?	Incident settings control incident creation and grouping; an automation rule is required to invoke the incident-triggered playbook.	Sentinel::Automation
In Microsoft Sentinel, what must be created before you can build a playbook?	An Azure Logic App.	Sentinel::Automation
A Microsoft Sentinel automation rule cannot select a playbook stored in RG1. Which least-privilege assignment should be made?	Assign Microsoft Sentinel Automation Contributor to the Azure Security Insights identity on RG1.	Sentinel::RBAC
In Microsoft Sentinel, what happens when several automation rules match the same incident?	They run in configured order, and each later rule evaluates the incident after earlier rules may have modified it.	Sentinel::Automation
In Microsoft Sentinel, when is an expiration date on an automation rule especially useful?	For temporary logic such as suppressing or closing expected incidents during a penetration test or maintenance window.	Sentinel::Automation
In Microsoft Sentinel, which feature should be used to visualise sign-in activity over time in an interactive report?	A workbook.	Sentinel::Workbooks
In Microsoft Sentinel, what is the difference between a workbook and an analytics rule?	A workbook visualises and explores data; an analytics rule detects matching activity and creates alerts or incidents.	Sentinel::Workbooks
In Microsoft Sentinel, which workbook visualisation should display query results in a table with conditional formatting or heatmaps?	A Grid visualisation.	Sentinel::Workbooks
In Microsoft Sentinel, which markup language is used in workbook text visualisations?	Markdown.	Sentinel::Workbooks
In Microsoft Sentinel, where is a custom workbook stored?	As an Azure Workbook resource in the resource group associated with the Sentinel workspace.	Sentinel::Workbooks
In Microsoft Sentinel ASIM, what is the difference between a unifying parser and a source-specific parser?	A unifying parser combines all supported sources for a schema; a source-specific parser normalises one product or source.	Sentinel::ASIM
In Microsoft Sentinel, which ASIM parser should analysts normally call when they want a query to work across all normalised sources for a schema?	The unifying parser.	Sentinel::ASIM
Why should an ASIM filtering parameter such as <code>starttime=ago(1d)</code> be passed inside the parser call when supported?	It reduces the data before parsing, improving query efficiency.	Sentinel::ASIM
In Microsoft Sentinel, how can you prevent automatic updates from changing the built-in ASIM parser version used by your queries?	Build a custom unifying parser that explicitly includes the required versioned built-in source parser and excludes automatic substitution of other built-in parsers.	Sentinel::ASIM
In Microsoft Sentinel, which DCR transformation input represents each incoming record?	The virtual table <code>source</code>.	Sentinel::DCR
In a Microsoft Sentinel DCR transformation, which KQL operators commonly filter, enrich and shape an incoming record?	<code>where</code>, <code>extend</code> and <code>project</code>.	Sentinel::DCR
In Microsoft Sentinel, what does UEBA do?	It builds behavioural profiles for users and entities, then identifies anomalous activity by comparing current behaviour with baselines and peer context.	Sentinel::UEBA
In Microsoft Sentinel, what is the difference between a behaviour, an anomaly and an alert?	A behaviour is a contextual activity summary, an anomaly is a deviation from a baseline, and an alert signals a potential security issue requiring attention.	Sentinel::UEBA
In Microsoft Sentinel, which UEBA view should an analyst use to investigate consolidated activity and behavioural context for a user or host?	The entity page.	Sentinel::UEBA
In Microsoft Sentinel, which table contains UEBA behaviour metadata and categories?	<code>BehaviorInfo</code>.	Sentinel::Tables
In Microsoft Sentinel, which table links behaviours to users, hosts, IP addresses and other associated entities?	<code>BehaviorEntities</code>.	Sentinel::Tables
In the Microsoft Sentinel MITRE ATT&amp;CK coverage matrix, how do you see both active detections and additional available detections for a technique?	Select the technique and review its details pane.	Sentinel::MITRE
In Microsoft Sentinel, what is the main purpose of the MITRE ATT&amp;CK coverage matrix?	To evaluate detection coverage by tactic and technique and identify gaps where additional detections are available.	Sentinel::MITRE
In Microsoft Sentinel, which source-control systems can be connected for repository-based deployment of Sentinel content?	GitHub and Azure DevOps.	Sentinel::Repositories
In Microsoft Sentinel repositories, why should parsers and hunting queries be considered together during deployment?	Both use the Saved Searches API, so deploying one content type from a branch can deploy both when both are present.	Sentinel::Repositories
