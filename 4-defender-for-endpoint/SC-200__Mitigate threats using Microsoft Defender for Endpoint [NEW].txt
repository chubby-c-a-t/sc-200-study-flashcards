An administrator needs to prevent a known, benign custom log-clearing application from generating Defender alerts without disabling detections for other applications. What feature should be configured?	An Alert Suppression Rule. (Controls alert context by specifying alert title, IoC, or process conditions to automatically dismiss known false positives).	MDE::Response
An analyst investigating a high-severity alert on a Windows endpoint needs to inspect the detailed chronological sequence of local system events that occurred immediately before the alert was triggered. Where in the Defender portal should they look?	The Timeline tab on the specific Device page. (Go Hunt queries Advanced Hunting for related events, but the Timeline tab provides the pre-alert chronological event history on the endpoint).	MDE::Investigation
A SOC team needs a complete snapshot of forensic artifacts (running processes, network connections, autorun entries, and scheduled tasks) from a compromised endpoint directly from the portal without initiating an interactive Live Response session. Which action should they take?	"Select ""Collect investigation package"". (Gathers forensic artifacts and downloads them as a single ZIP file for offline analysis)."	MDE::Response
To identify the full scope of an active incident affecting both Windows 11 and macOS endpoints across an organization, which Defender portal feature should be used to run queries across device telemetry?	Advanced Hunting. (Executes KQL queries across cross-platform endpoint tables like DeviceEvents and DeviceProcessEvents).	MDE::Hunting
"In Microsoft Defender for Endpoint, what is the primary operational difference between the ""Isolate Device"" action and the ""Contain Device"" action?"	Isolate disconnects an onboarded managed device from the network (except for Defender portal connectivity); Contain blocks network communication with an unmanaged device discovered on the network.	MDE::Response
A third-party non-Microsoft antivirus is running as the primary active protection on a Windows 11 endpoint. Which MDE capability ensures that Defender still detects and remediates malicious artifacts post-execution?	EDR in Block Mode. (Enables EDR capabilities to detect and remediate malicious behavior even when Defender Antivirus is in Passive mode).	MDE::Protection
An analyst runs an Advanced Hunting query against the DeviceEvents table to hunt for suspicious remote access activity across Windows 11, macOS, and Android devices. Which devices will NOT return records in this table?	Android devices. (Android devices onboarded to MDE do not populate the DeviceEvents table in Advanced Hunting).	MDE::Hunting
Which Device Discovery mode in Defender for Endpoint uses both passive network monitoring and active network probing to discover unmanaged devices on the subnet?	Standard Discovery. (Basic Discovery relies on passive network monitoring only).	MDE::Discovery
What health status is assigned to an onboarded endpoint in Defender for Endpoint when it stops sending telemetry and heartbeats to the cloud for more than 7 consecutive days?	Inactive.	MDE::Investigation
Which specific artifact included in a Defender for Endpoint Investigation Package is most useful for identifying persistence mechanisms established by an attacker?	Autoruns data. (Network Connections data identifies C2/lateral movement; Prefetch files identify recently executed binaries).	MDE::Forensics
An administrator wants to deploy an Attack Surface Reduction (ASR) rule across the organization without impacting business operations. Which rule state should be used during initial deployment to evaluate impact?	Audit mode. (Logs events in the portal without blocking user activity. Warn mode blocks execution until the user manually bypasses it).	MDE::ASR
Which Attack Surface Reduction (ASR) rule explicitly prevents malware from dumping process memory to steal cached NTLM or Kerberos credentials?	Block credential stealing from the Windows local security authority subsystem (lsass.exe).	MDE::ASR
Which Microsoft Entra and Microsoft 365 roles grant sufficient administrative permissions to modify security settings in Microsoft Defender XDR?	Global Administrator (Entra ID) or Security Administrator (Entra ID or M365 role group). Security Reader provides read-only access.	MDE::Administration
In Defender for Endpoint asset management, how do Device Risk Level and Device Exposure Level differ?	Device Risk Level reflects active threat alerts and detected malicious behavior on the device; Device Exposure Level reflects unpatched vulnerabilities and security misconfigurations (TVM).	MDE::Investigation
An analyst needs to restrict execution on a compromised endpoint so that only Microsoft-signed applications can run while an investigation is underway. Which device response action should be used?	Restrict App Execution.	MDE::Response
What prerequisite must be configured before Microsoft Intune can enforce device risk-based Conditional Access policies using Defender for Endpoint threat data?	Enable the Microsoft Intune connection in Defender for Endpoint Settings and configure the compliance policy rule in Intune.	MDE::Integration
An organization needs to block corporate devices from establishing connections to known malicious domains, URLs, or IP addresses across all browsers. Which Defender feature should be configured?	Custom Indicators (Network Indicators) with the action set to Block.	MDE::Protection
Why should administrators create custom Device Groups in Defender for Endpoint rather than leaving all devices in the unassigned group?	Device Groups establish RBAC access boundaries for SOC analysts, set automated remediation approval levels, and target configuration policies.	MDE::Administration
"What happens when an end user triggers an Attack Surface Reduction (ASR) rule that is configured in ""Warn"" mode?"	The action is initially blocked, but the user is presented with a prompt allowing them to bypass the warning and execute the application.	MDE::ASR
Which forensic artifact inside the Defender for Endpoint Investigation Package provides evidence of recently executed binaries, including execution timestamps and run counts?	Prefetch files.	MDE::Forensics
