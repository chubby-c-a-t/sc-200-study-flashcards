What fundamental characteristic differentiates true proactive threat hunting from incident response, alert triage, or searching for known indicators?	Threat hunting is proactive and searches for threats or activities *not previously detected* without relying solely on known indicators of compromise (IOCs) like a specific bad IP.	Sentinel::ThreatHunting
What is the starting point and core driver of a proactive threat hunt when no known indicator is present?	A Hypothesis, typically based on operational threat intelligence and attacker tactics and techniques (TTPs).	Sentinel::ThreatHunting
What key traits define a strong, effective threat hunting hypothesis?	It must be time-bound and appropriately scoped (avoiding overly broad scopes like checking every instance of common binaries without context).	Sentinel::ThreatHunting
What is the difference between active coverage and simulated coverage in the Microsoft Sentinel MITRE ATT&CK coverage matrix?	Active coverage displays currently configured and enabled detection rules (scheduled, NRT, anomaly) mapped to techniques, while simulated coverage shows available but unconfigured rules in your workspace.	Sentinel::ThreatHunting
What key elements must be included when documenting a completed threat hunt?	What, how, and why the hunt was performed, inputs and outputs, how to replicate the hunt, and next steps (such as setting up new monitoring or improving detection capabilities).	Sentinel::ThreatHunting
How does searching for logs using a newly received malicious IP indicator differ from proactive threat hunting?	Searching logs with a known bad indicator is an indicator search/analysis process rather than true proactive threat hunting (which looks for undetected anomalies based on behavior).	Sentinel::ThreatHunting
When a threat-hunting query in Microsoft Sentinel is selected as a favorite (marked with a star), how does its execution behavior change on the Hunting page?	It runs automatically every time the Hunting page is opened.	Sentinel::ThreatHunting
What Log Analytics table stores bookmarked query results, notes, and tags created during threat-hunting investigations?	`HuntingBookmark`.	Sentinel::ThreatHunting
What structural container in Microsoft Sentinel organizes queries, bookmarks, mapped entities, comments, analytics rules, and incidents around a specific investigation hypothesis?	A hunt.	Sentinel::ThreatHunting
What options are available via the Incident Actions button on the Hunt toolbar when a bookmark is selected?	Creating a new incident or adding the bookmarked query results to an existing incident.	Sentinel::ThreatHunting
Which MITRE ATT&CK tactic category covers adversary techniques used to manipulate, disable, or damage physical control processes in ICS environments?	Impair Process Control.	Sentinel::ThreatHunting
In the SC-200 threat hunting lab, what specific KQL query filters on `AzureActivity` were used to identify accepted VM deletion events?	`where OperationName == 'Delete Virtual Machine'` and `where ActivityStatus == 'Accepted'`.	Sentinel::ThreatHunting
What suffix is automatically applied to search results tables generated by a Microsoft Sentinel search job?	`_SRCH`.	Sentinel::SearchAndRestore
What suffix is automatically applied to restored archive log tables in Microsoft Sentinel?	`_RST`.	Sentinel::SearchAndRestore
What is the maximum date range allowed when executing a Microsoft Sentinel search job?	Up to one year.	Sentinel::SearchAndRestore
What is the maximum duration timeout supported by a single search job?	Up to 24 hours.	Sentinel::SearchAndRestore
What are the execution and workspace limits regarding concurrent search jobs and daily search job executions?	Limited to 5 concurrent search jobs per workspace and 100 search job executions per day per workspace.	Sentinel::SearchAndRestore
What log types are supported for executing Microsoft Sentinel search jobs?	Analytics logs, Basic logs, and Auxiliary logs.	Sentinel::SearchAndRestore
What are the workspace limits for restoring archived log tables per week?	Up to 4 archived tables per workspace per week (with a maximum of 60 TB restored data and 2 concurrent restore jobs).	Sentinel::SearchAndRestore
Why do tables with the Auxiliary table plan not support data restore operations, and how should data be retrieved from them instead?	Auxiliary tables do not support direct data restore; instead, you must use a search job to retrieve data from long-term retention.	Sentinel::SearchAndRestore
What underlying data store and API mechanism do external tools like Python and PowerShell use to access Microsoft Sentinel data?	The Log Analytics data store accessed via a standard REST API.	Sentinel::Notebooks
What are the two primary Python libraries used to simplify API access and querying in Microsoft Sentinel notebooks?	`Kqlmagic` and `msticpy`.	Sentinel::Notebooks
What does the `msticpy` library stand for and what are its three central purposes for security investigators?	Microsoft Threat Intelligence Python Security Tools; it addresses (1) acquiring and enriching data, (2) analyzing data, and (3) visualizing data.	Sentinel::Notebooks
What are the two core components that make up a Microsoft Sentinel Jupyter Notebook?	(1) The browser-based interface where code and queries are entered/executed, and (2) the kernel responsible for parsing and executing the code on an Azure ML compute instance.	Sentinel::Notebooks
What open-source package is heavily integrated into Microsoft Sentinel notebooks to provide pre-built security investigation, enrichment, and hunting functions?	`msticpy`.	Sentinel::Notebooks
